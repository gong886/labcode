### 2.1 练习一：加载应用程序并执行（需要编码）
首先了解打开文件的处理流程，然后参考本实验后续的文件读写操作的过程分析，填写在 kern/fs/sfs/sfs_inode.c中 的sfs_io_nolock()函数，实现读文件中数据的代码。

#### 打开文件的处理流程

1.  用户态程序调用 `open` 系统调用，最终触发内核态的 `vfs_open` 函数。`vfs_open` 需要获取文件对应的 inode，因此调用 `vfs_lookup`。
2.  `vfs_lookup` 调用特定文件系统（这里是 SFS）的 `sfs_lookup` 函数。
3.  `sfs_lookup` 调用 `sfs_lookup_once`，该函数在给定的目录中查找指定文件名的目录项。它使用 `sfs_dirent_search_nolock` 遍历目录的磁盘块，匹配文件名，找到对应的 inode 编号。
4.  找到 `ino` 后，调用 `sfs_load_inode`。该函数首先检查 inode 是否已在内存中。如果不在，则分配一个新的 `inode` 结构，并根据 `ino` 从磁盘读取 `sfs_disk_inode` 数据，初始化内存中的 `sfs_inode`，最后将其链接到 SFS 的 inode 列表中。

#### 设计思路

`sfs_io_nolock` 函数主要负责将内存缓冲区 `buf` 中的数据写入文件，或者将文件中的数据读取到 `buf` 中。由于文件在磁盘上是以块为单位存储的，而读写请求的偏移量和长度可能不是块对齐的，因此需要分三种情况处理：

1.  起始非对齐部分：如果读写操作的起始偏移量 `offset` 不是块对齐的，则需要先处理该块中从 `offset` 开始到块结束的部分。这部分通常使用 `sfs_buf_op`进行非对齐读写。
2.  中间对齐块部分：处理完起始非对齐部分后，如果剩余的读写长度超过一个块的大小，则可以按块进行批量读写。这部分是读写操作的主体，使用 `sfs_block_op`直接对整个块进行操作，效率较高。
3.  结尾非对齐部分：处理完中间的对齐块后，如果还有剩余数据，则说明结束位置不是块对齐的。这部分同样使用 `sfs_buf_op` 处理该块从起始位置到结束位置的数据。

在上述每一步中，都需要先调用 `sfs_bmap_load_nolock` 函数，根据文件的逻辑块号获取其在磁盘上的物理块号。如果是在写操作中且该块尚未分配，`sfs_bmap_load_nolock` 还会负责分配新的磁盘块。

#### 代码实现

```c
    //对齐部分
    if ((blkoff = offset % SFS_BLKSIZE) != 0) {
        size = (nblks != 0) ? (SFS_BLKSIZE - blkoff) : (endpos - offset);
        if ((ret = sfs_bmap_load_nolock(sfs, sin, blkno, &ino)) != 0) {
            return ret;
        }
        if ((ret = sfs_buf_op(sfs, buf, size, ino, blkoff)) != 0) {
            return ret;
        }
        alen += size;
        buf += size;
        if (nblks == 0) {
            goto out;
        }
        blkno ++;
        nblks --;
    }

    // 中间对齐块
    if (nblks > 0) {
        int i;
        for (i = 0; i < nblks; i ++) {
            if ((ret = sfs_bmap_load_nolock(sfs, sin, blkno, &ino)) != 0) {
                return ret;
            }
            if ((ret = sfs_block_op(sfs, buf, ino, 1)) != 0) {
                return ret;
            }
            alen += SFS_BLKSIZE;
            buf += SFS_BLKSIZE;
            blkno ++;
        }
    }

    // 结束非对齐部分
    if ((size = endpos % SFS_BLKSIZE) != 0) {
        if ((ret = sfs_bmap_load_nolock(sfs, sin, blkno, &ino)) != 0) {
            return ret;
        }
        if ((ret = sfs_buf_op(sfs, buf, size, ino, 0)) != 0) {
            return ret;
        }
        alen += size;
    }
```
